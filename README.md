## 环境要求

- Android Studio（最新稳定版）
- JDK 11
- Android 设备 / 模拟器，系统版本 **Android 10（API 29）及以上**
- 编译目标 `compileSdk / targetSdk = 37`

## 复现步骤

1. 用 Android Studio 打开本仓库根目录。
2. 等待 Gradle 同步完成（依赖见 `app/build.gradle.kts`，使用 Version Catalog `gradle/libs.versions.toml`）。
3. 连接设备或启动模拟器，开启 **"允许安装未知来源应用"** 与 **"悬浮窗权限"**（首次运行会引导）。
4. 执行构建：
   ```bash
   ./gradlew assembleDebug
   ```
5. 安装生成的 `app-debug.apk` 到设备并运行。

## 功能概览

- **浮窗宠物**：常驻屏幕的 2D 宠物，可拖动、抛掷，受重力影响掉落/贴边。
- **物理与姿态**：重力抛掷开关、四边重力（上下/左右）、脚朝向（含体感倾斜）、吸附阈值。
- **碎碎念**：定时在宠物旁显示随机文案（"芝麻酥"主题），支持多种**退场/显形过渡特效**：
  - 噪点溶解 / 闪烁噪点 / 直接消失 / 空格溶解 / 黑框溶解（进出场对称）。
- **随机模式**：按可配置项周期性随机改写配置（含"变变变"触发提示）。
- **设置页**：大小、边界偏移、碎碎念、吸附判定迁移、重力与随机项等。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `SYSTEM_ALERT_WINDOW` | 悬浮窗显示宠物（核心功能，需用户手动授予） |
| `VIBRATE` | 长按/交互振动反馈（安装即授予） |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | 前台服务常驻宠物 |
| `POST_NOTIFICATIONS` | 前台服务通知 |
| `RECEIVE_BOOT_COMPLETED` | 开机自启宠物（可选） |

**本应用不声明任何网络权限，不与外部服务器通信。**
